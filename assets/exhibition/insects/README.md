# Insects exhibition archival images

These 18 WebP image files are the locally hosted visual assets for `insects-interactive-final.html`. They replace time-limited or unavailable Omeka image addresses. The 21 image uses in the exhibition include repeated detail views of a source plate.

The glass-bottle and bamboo-tube release photographs both come from `赤眼蜂防治稻纵卷叶螟` (Guangdong, 1973), printed p. 14 (upper and lower photos). Their source file snapshots were supplied by the curator and previously prepared from the scanned booklet.

Source citations for all other images are visible directly under each exhibition image in the HTML and documented in `research/insects-image-sources.csv` and `research/source-publications.csv`.

Only the selected exhibition images are stored here, not the underlying full scanned books. Copyright/reproduction status of individual historical source images must still be reviewed before broader distribution or reuse.
